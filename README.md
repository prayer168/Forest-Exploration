# 森林探索 Forest Adventure

一個以第一人稱在無限延伸的森林裡自由探索的 3D 網頁遊戲。沒有戰鬥、沒有計分,單純走進一座活著的森林裡看看。

**線上遊玩:** https://prayer168.github.io/Forest-Exploration/

---

## 操作方式

| 操作 | 動作 |
|---|---|
| 方向鍵 ↑ ↓ ← → (或 W A S D) | 前進 / 後退 / 左移 / 右移 |
| 按住滑鼠左鍵拖曳 | 環視鏡頭(上下左右) |
| 滑鼠移到畫面左右邊緣 | 緩慢轉向 |
| 滑鼠滾輪 | 前進 / 後退 |

## 特色

**無限的森林**
世界以區塊為單位在玩家周圍即時生成,離開後卸載,往任何方向走都不會遇到盡頭。地形與植被由座標決定,所以走回頭路時,同一個地方永遠是同一片林子。

**分層的植被**
高大喬木、中層喬木、低矮灌木、樹蕨、草叢、蕨類與藤蔓構成六個層次。樹木分成突出層、樹冠層、中層與林下層四種尺寸等級,高度、樹幹粗細與葉色各自隨機,林相高低錯落。

**活著的生態系**
每種動物有自己的行為模式與察覺距離:

- **山豬、山羌** — 閒晃與覓食交替,察覺到人先停下警戒,再靠近就高速逃離
- **臺灣獼猴** — 群體行動,不會馬上逃走,會保持距離觀察你
- **臺灣黑熊** — 稀有,不怕人,但會主動維持安全距離
- **老鷹** — 高空大範圍盤旋滑翔
- **蝴蝶、蜻蜓** — 低空隨機漫遊
- **蛇** — 爬行時身體左右擺動,受驚會竄逃
- **蜘蛛** — 部分在地面爬行,部分停在蜘蛛網上
- **獨角仙** — 在地面緩慢爬行

**溪流與地貌**
由兩套獨立地形場產生的無限分支水系,溪水會下切出河床,走進去是涉水而過。溪畔有沙石灘與礫石,地面鋪滿落葉、枯枝、碎石與腐植質色塊。

**天空與光影**
漸層天空、看得見的太陽與光暈、緩慢飄移的立體積雲。陽光的陰影範圍跟著玩家移動,走到任何地方樹影都正常投射。

## 技術架構

純 Three.js 與原生 JavaScript,無建置流程,無外部相依套件(Three.js 由 CDN 以 import map 載入)。

| 檔案 | 職責 |
|---|---|
| `src/rng.js` | 決定性雜湊、value noise 與 fBm |
| `src/terrain.js` | 地形高度場、溪流網路、地表顏色 |
| `src/flora.js` | 樹木原型、草叢與蕨類幾何、地面雜物 |
| `src/chunks.js` | 區塊串流:生成、卸載、細節升級 |
| `src/sky.js` | 天空穹頂、太陽、雲、陽光與陰影 |
| `src/fauna.js` | 動物模型與行為狀態機 |
| `src/main.js` | 場景組裝、操作控制、主迴圈 |

效能作法:同一區塊的所有樹木烘焙成單一頂點著色網格,地被植物與雜物以 instancing 繪製,遠處區塊略過地被生成並靠霧氣遮蔽。整體約 71 萬個三角形、371 個繪製呼叫。

詳細的設計構想與後續規劃見 [GAME_DESIGN.md](GAME_DESIGN.md)。
